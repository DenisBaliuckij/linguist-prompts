Здесь собраны [арабские промпты 4 и 5](prompts.md), проверенные в бесплатном DeepSeek без дополнительного типологического профиля. Правила лемматизации строились по онтологии и корпусным парам «словоформа — лемма» из Universal Dependencies. Этап 4 адаптирован из [армянского PR №28](https://github.com/DenisBaliuckij/linguist-prompts/pull/28), этап 5 — из описания итерации в том же PR.

Для независимой оценки откройте отдельный чат. Промпт 5 передайте вместе с отчётом оценщика в чат, где создавался лемматизатор. В тексте сохранён отчёт арабского прогона; при повторении замените его своим. Исправления проверяйте на отдельной выборке.
