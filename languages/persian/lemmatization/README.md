# Persian · lemmatization

Four prompts that build a rule-based lemmatizer for Standard (Iranian) Persian and measure it honestly: (1) build the language ontology `OntoPersian.json` from an attached grammar, a verb stem list and a word list, (2) extract disjoint `development` and `holdout` gold use-cases from UD Persian-Seraji, whose lemmas are annotated manually, (3) generate `persian_lemmatizer.py` from the ontology, the lexicon files and the development set only, (4) evaluate it on the hidden holdout set with a full CSV and an error report. Run them in order, each in a new chat; never show the holdout set to the model before stage 4. In Seraji the verb lemma is the past stem (رفت, کرد), not the infinitive.

The prompts were run once end to end (October 2026). Sources: Wikipedia grammar page, the Hazm data files (verb stems and word list), UniMorph `fas`, the Seraji README. The lemmatizer reached 253/301 = 84.1% exact match on the holdout set (VERB 93.1%, AUX 87.1%, NOUN 74.2%, ADJ 18/19), and 60.1% without the development lexicon. Gold UPOS and features were given as input. 19 of the 48 errors are Arabic broken plurals (دلایل -> دلیل, مسائل -> مسأله): attach a list of broken plurals with their singulars in stage 1. Seraji conventions that its README does not mention (for example forms of شدن annotated with the lemma کرد) are learned from the development set in stage 3. A blind replication with Claude Opus (one attempt per stage, no code execution, same holdout set) reached 255/301 = 84.7%; with Qwen3.8-27B on the free OpenRouter tier the run failed because long answers were truncated (invalid ontology JSON, cut-off code).
