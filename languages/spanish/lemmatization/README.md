# Spanish · lemmatization

Этот набор задаёт полный воспроизводимый конвейер для современного письменного испанского языка: собрать онтологию из указанных источников, извлечь независимые размеченные примеры, сгенерировать rule-based лемматизатор и оценить его на отложенной выборке. Его цель - рабочий лемматизатор с широким покрытием, а не демонстрация нескольких окончаний.

Промпты выполняются строго по порядку. Материалы для оценки нельзя передавать модели при создании онтологии, словаря исключений или кода: иначе метрика не показывает способность лемматизатора работать с новыми данными. Для эталонных use-cases подходит UD Spanish AnCora: в нём есть лемма, часть речи и грамматические признаки для каждого токена. При использовании корпуса сохраняйте URL, лицензию, идентификаторы предложений и токенов.

Онтология и лемматизатор должны покрывать все парадигмы и лексические исключения, которые есть в переданных источниках. Нерегулярные глаголы, омонимия форм, апокопа, восстановление акцентов и выбор класса `-er`/`-ir` не должны маскироваться эвристиками: для них нужен лексикон или явная запись о пробеле в данных. Финальный отчёт показывает это покрытие и все оставшиеся ошибки.
