# Latin · lemmatization

Four prompts that build a rule-based lemmatizer for Latin and measure it honestly: (1) build the language ontology `OntoLatin.json` from an attached reference grammar and a machine-readable dictionary, (2) extract disjoint `development` and `holdout` gold use-cases from one UD Latin treebank with manual lemmas, (3) generate `latin_lemmatizer.py` from the ontology, the dictionary and the development set only, (4) evaluate it on the hidden holdout set with a full CSV and an error report. Run them in order, each in a new chat; never show the holdout set to the model before stage 4. UD Latin treebanks follow different lemma conventions, so use one treebank per experiment.

The prompts were run once end to end (October 2026). Sources: Allen & Greenough's New Latin Grammar (Alpheios/DCC edition), Whitaker's Words dictionary files, UniMorph `lat`, UD Latin documentation. Gold set: UD Latin-PROIEL. The lemmatizer reached 272/300 = 90.7% exact match on the holdout set (VERB 89.6%, NOUN 92.2%, PRON 97.6%, PROPN 7/10), and 83.7% without the development lexicon. Gold UPOS and features were given as input. Most remaining errors are homographs that need context (vis: volo / viso) and spelling or convention differences between the dictionary and the corpus (inpono / impono, Iudaei as a plural-only lemma). A blind replication with Claude Opus (one attempt per stage, no code execution, same holdout set) reached 255/300 = 85.0%; with Qwen3.8-27B on the free OpenRouter tier the run failed because long answers were truncated (invalid ontology JSON, cut-off code).
