Ты — эксперт по китайскому языку и Python. Создай rule-based лемматизатор для китайского языка на основе онтологии OntoChinese.json.

Контекст языка
- Морфологический тип: изолирующий
- Порядок слов: SVO
- Категории: аспект, модальность, классификаторы
- Особенности: тоны, классификаторы, аспектные частицы
- Письменность: 汉字 + пиньинь
- Irregular forms: 俩 (= 两个), 仨 (= 三个), 甭 (= 不用), 别 (= 不要), 冇 (диалектное отрицание), 卅 (= 三十), 廿 (= 二十), 咋 (= 怎么), 啥 (= 什么), 俺 (= 我), 咱 (= 咱们), 怹 (вежливое 他), 妳 (женское 你), 牠 (неодушевлённое 它), 祂 (божественное 他), 这不 (= 这不是), 那啥 (= 那个什么)

Требования

Вход
Онтология JSON, заполненная по GOLD OntoLing.

Выход
Класс ChineseLemmatizer с методами:
- lemmatize(word, pos=None) -> Dict — лемма, POS, features, confidence
- lemmatize_sentence(sentence) -> List[Dict] — по токенам
- batch_lemmatize(words) -> List[Dict]
- generate_forms(lemma, pos) -> List[Dict] — генерация форм
- evaluate(test_data) -> Dict — точность

Архитектура
- detect_pos(word) — определение части речи
- _strip_noun_affixes(word) — снятие аффиксов существительного
- _strip_verb_affixes(word) — снятие аффиксов глагола
- _lemmatize_noun/verb/adj/pron/num/classifier/particle/conj — методы для каждого POS
- _handle_composite(text) — составные формы

Порядок проверок в detect_pos
1. Точные словари (pronouns, numerals, adjectives, classifiers, conjunctions, particles, nouns, derived_nouns)
2. Глагольные стемы и аспектные формы
3. Притяжательные частицы 的 (STRICT проверка, ДО verb)
4. Суффиксы прилагательных (сравнительные конструкции 比, 更, 最)
5. Адъективные форманты (деривационные)
6. Порядковые числительные (第 + numeral)
7. Инфинитивы и модальные конструкции
8. Глагольные префиксы и результативные морфемы
9. Глагольные окончания (STRICT проверка: 了, 着, 过)
10. Суффиксы множественного числа (们)
11. Падежные частицы и послелоги
12. Дефолт: noun

Словари (в __init__, если необходимо)
- known_nouns, known_adjectives, known_adverbs
- known_verbs, stem_to_infinitive, infinitive_to_past, infinitive_to_stem
- aspect_stems, all_verb_stems
- personal_pronouns, numerals, classifiers, postpositions, conjunctions, particles
- irregular_comparatives (если есть)
- known_derived_nouns (whitelist лексикализованных слов)
- abstract_noun_bases (для -性, -化, -度 и аналогов)

Правила из онтологии
Загружай из онтологии:
- Plural suffixes: ["们"]
- Case suffixes: [] (в китайском нет падежных суффиксов в традиционном понимании; падежные отношения выражаются послелогами и порядком слов)
- Possessive suffixes: ["的"]
- Verb endings: ["了", "着", "过"]
- Verb prefixes: [] (аспектные маркеры следуют за глаголом; препозитивный прогрессив 在/正在 — отдельный случай)
- Derivational suffixes: ["性", "化", "度", "者", "家", "员", "手", "人"]

Особенности китайского языка
- Аспектные маркеры: 了 (перфектив), 着 (дуратив/прогрессив), 过 (экспериенциальный аспект) — следуют непосредственно за глаголом
- Прогрессивный аспект также выражается препозитивным 在 или 正在 + глагол
- Множественное число: 们 используется с личными местоимениями и одушевлёнными существительными (люди, иногда животные); с неодушевлёнными — только в стилистических целях
- Притяжательная частица 的: связывает определение и определяемое, маркирует принадлежность
- Сравнительные конструкции: 比 + X + 更/最 + прилагательное; 比字句 для сравнения, 最 для суперлатива
- Порядковые числительные: 第 + числительное (第一, 第二), либо числительное + классификатор + существительное (三楼, 四号)
- Классификаторы: обязательны перед существительным при числительном; 个 — универсальный классификатор; специализированные: 辆 (автомобили), 本 (книги), 张 (плоские предметы) и др.
- Послелоги: 里, 外, 上, 下, 前, 后 — выражают пространственные отношения, следуют за существительным (家里, 校外, 桌上)
- Структурные частицы: 的 (атрибутивная), 地 (адвербиальная), 得 (комплементарная)
- Союзы: 和, 跟, 同, 与 (соединительные), 或, 或者 (разделительные), 但, 但是 (противительные), 因为...所以 (причинные), 虽然...但是 (уступительные)
- Деривационные суффиксы: 者, 家, 员, 手 (агент), 性, 度 (абстрактные существительные), 化 (процесс/преобразование)

Fallback
Если не нашли — вернуть исходное слово с confidence=0.3.

Составные формы
Обрабатывать:
- Редупликация глаголов: 看看, 试试 (смягчение/краткость)
- Редупликация прилагательных: 红红的, 干干净净
- Глагол + аспектный маркер: 吃了, 看着, 去过
- Глагол + результативная морфема: 看完, 听懂, 做好
- Существительное + 们: 学生们, 朋友们
- Определение + 的 + существительное: 我的书, 红色的花
- Числительное + классификатор + существительное: 三辆车, 五本书
- 第 + числительное: 第一, 第二
