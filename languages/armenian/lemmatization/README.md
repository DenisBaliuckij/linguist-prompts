# Armenian · lemmatization

Four prompts that build a rule-based lemmatizer for Modern Eastern Armenian (hye) and measure it honestly: (1) build the language ontology `OntoArmenian.json` from attached grammars and dictionaries, (2) extract disjoint `development` and `holdout` gold use-cases from UD Armenian-ArmTDP, whose lemmas are annotated manually, (3) generate `armenian_lemmatizer.py` from the ontology and the development set only, (4) evaluate it on the hidden holdout set with a full CSV and an error report. Run them in order, each in a new chat; never show the holdout set to the model before stage 4. Western Armenian is a different standard and needs its own sources and treebank.

The prompts were run once end to end (October 2026, sources: Wikipedia grammar pages, UniMorph `hye` paradigms, the UD Armenian documentation). The lemmatizer reached 273/302 = 90.4% exact match on the holdout set (NOUN 96.2%, VERB 83.8%, AUX 100%, PROPN 81.0%, PRON 2/7), and 83.8% without the development lexicon. Gold UPOS and features were given as input. Most remaining errors are pronoun and suppletive verb paradigms that were missing from the sources, so attach a full reference grammar for stage 1. The prompts in this folder already include the corrections that run showed were needed: `str.lower()` instead of `casefold()` because of the ligature և, UD feature names, defaults backed by lexicon frequencies, and cross-validation on the development set.
